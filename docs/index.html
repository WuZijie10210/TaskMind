从对话走向成果

让复杂学习任务有主线，也有探索的空间。

AI 对话能迅速打开思路，但长任务中的信息容易散落，临时探索也会打乱主线。TaskMind 探索如何把任务、支线和成果组织成可以继续推进的工作空间。

可交互 Web App · 公开演示版

问题与假设

一次课程汇报或行业研究往往需要拆解问题、尝试多个方向、保留中间结论。单一聊天时间线很难同时承载这些动作。我的设计假设是：如果用户能分支探索、审核阶段成果，并在后续对话中明确引用它们，就能更容易延续复杂任务。这个假设尚未经过真实用户数据验证。

核心体验

01创建 Task

从一句话开始，明确当前要推进的任务。

02主线与支线

保留主目标，同时为问题开辟独立探索空间。

03确认成果

AI 提出候选，用户审核后保存为 Artifact。

04显式复用

在新消息中用 @成果 或 @任务引入相关内容。

我做出的产品决策

冻结支线起点

支线创建时保存主线快照。之后主线继续发展，也不会悄悄改变支线的背景。

成果由人确认

模型擅长整理候选，但哪些结论值得长期保留，需要由使用者判断。

冻结引用内容

每次引用保存当时传给模型的成果快照，后续修改标题或删除成果不会改写历史语境。

下一步验证

邀请目标用户完成一项真实的多轮任务，观察他们是否自发创建支线、能否找到已保存成果、是否理解引用行为。根据观察调整信息架构和默认引导，再处理长对话的上下文预算。
